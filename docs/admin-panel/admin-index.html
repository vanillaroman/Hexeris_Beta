Export a person's messages
Produces one file with the decrypted correspondence of a single employee for a period — direct chats and the groups they belong to. Intended for internal investigations and lawful requests. Every export is recorded in the Audit Log together with the reason you enter below.
Dates are inclusive. Empty = last 30 days.
What the file does not contain. Attachment files themselves are not bundled — the export lists their stored names, and the files remain encrypted at rest in UPLOAD_DIR. Messages in a group the employee has left are included only where they are the sender: membership history is not retained.
Add user
